# 📋 MVP Scoping & Strategic Roadmap

This document defines the **Proof of Viability** for **Accessible Academic**. Our goal is to demonstrate a seamless pipeline that transforms raw audio into a comprehensive learning package.

## 🎯 MVP Objectives
The primary focus is building a robust core system that provides immediate pedagogical value to students.

### ✅ In-Scope (Phase 1)
* **Core AI Engine:** A web platform capable of processing raw media into study materials.
* **Smart Media Player:** A synchronized interface where the transcript moves in real-time with the audio.
* **Knowledge Extraction:** Automatic generation of topics, summaries, and flashcards.

### 🚧 Out-of-Scope (Future Enhancements)
* Full automation with institutional VOD systems like Panopto or Moodle (Handled manually for MVP demonstration).
