Also tested against Whisper

Same recording, OpenAI’s own speech model

On ordinary passages the two transcripts are nearly identical. In the single hardest passage in the lecture — overlapping questions from the audience — ours stays readable where Whisper’s own transcript breaks into noise.

98:32 A student asks about linear-time complexity
Whisper
…לא בזמן לינארים. תצודק אותו. בסדר? להיברילות…
Accessible Academic
…בסדר להגיד שזה קורה בזמן לינארי. כן, זה קורה בזמן לינארי, צודק. בסדר?…
Method. Both transcripts cover the same 2:12:44 recording. Neither is ground truth, so both were scored against a third, independent engine (Whisper large-v3-turbo, run locally) over ten passages sampled evenly across the lecture. Windows are snapped to Panopto’s own segment boundaries so all three transcripts describe exactly the same audio. The reference has its own errors, which affect both systems alike and favour neither.
